LayoutScale

Scale applied to panel sizes and anchor offsets. The HUD is laid out on a compact base canvas (Godot's 1152×648 default), where the bottom-left / bottom-right panels sit close to the centred action and skill bars. Letting the panels grow past their design size makes them collide with the centre bars, so layout growth is capped at 1.0 while ScaledFontSize(int) keeps scaling text fully for readability (text wraps, clips or scrolls inside its panel rather than pushing the panel wider).

public static float LayoutScale { get; }
